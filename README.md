# 📊 Prime Video Dashboard Analysis (Tableau)

## 🔹 Project Overview
This project presents an **interactive Tableau dashboard** that analyzes Prime Video movies and TV shows. It transforms raw data into meaningful insights, helping understand content distribution based on **genre, country, ratings, release year, and duration**.

---

## 🔹 Features

- 🌍 **Global Content Distribution**  
  Visual representation of total shows by country using a world map.

- 🎭 **Top Genres Analysis**  
  Displays the most popular genres using a bar chart.

- 🎬 **Content Type Breakdown**  
  Comparison between Movies and TV Shows using a donut chart.

- 📅 **Trend Over Time**  
  Growth of content over the years based on release year.

- ⭐ **Ratings Distribution**  
  Analysis of audience ratings (13+, 16+, ALL, etc.).

- 📝 **Detailed Information Panel**  
  Displays:
  - Title  
  - Cast  
  - Description  
  - Duration  
  - Release Year  

---

## 🔹 Tools & Technologies

- 📊 Tableau Desktop (Public Edition)  
- 🐍 Python (Optional for preprocessing)  
- 📁 Dataset: Prime Video Movies & TV Shows  

---

## 🔹 Insights

- Drama and Comedy are the most dominant genres  
- Movies significantly outnumber TV Shows  
- Rapid growth in content after 2015  
- High content contribution from countries like the US and India

## 🔹 How to Use

   - Genre  
   - Release Year  
   - Type  
   - Title  
4. Explore the interactive dashboard
